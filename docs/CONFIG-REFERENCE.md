# GTi CONFIG.TXT — Key Reference

_Auto-generated by the `gotek-docs` skill from the firmware source — the firmware is the source of truth. Do not hand-edit; regenerate after a build. Reference board: **Gotek_JC3248 `A600-lab1-JC3248-hfe2`**; the 7″ P4 (`5.9.42-lab7-P4G7-ipf3`) writes the same keys plus `NEO`. Regenerated 2026-10-17 (kodak80 fork: wireless HFE, `LIBRARY=`, IPF on the 7″ P4)._

Drop these lines into `CONFIG.TXT` at the root of the SD card (one `KEY=value` per line). Most also have an on-screen toggle — you rarely need to hand-edit. Keys are listed in the order the firmware's own template writes them.

| Key | Default | What it does |
|-----|---------|--------------|
| `THEME` | `0` | Theme: 0=NAVY 1=EMBER 2=MATRIX 3=PAPER 4=SYNTH 5=GOLD 6=OMEGA |
| `MODE` | `STANDALONE` | Transfer mode: STANDALONE (USB to Gotek) or WIRELESS (ESP-NOW to dongle) |
| `CAROUSEL` | `OFF` | CAROUSEL: default boot view. OFF=game list, ON=cover reel, LAST=restore last view. |
| `LOOP` | `0` | Loop cracktro splash: 1=loop until tapped, 0=auto-dismiss after 6s |
| `CRACKTRO` | `0` | Boot cracktro style: 0=random each boot, or pick one: 1=COPPER CLASSIC 2=STARFIELD 3=RAINBOW RASTER 4=PLASMA 5=BOING BALL 6=SYNTHWAVE 7=OMEGAWARE |
| `DIAGDISP` | `OFF` | DIAG-DISP: live diagnostic overlay box (FPS / free SRAM+PSRAM / uptime / CPU temp). ON or OFF. |
| `NOCACHE` | `OFF` | NOCACHE: ON = ignore every on-SD cache (.index .gamecache .nfocache micro .tnl). Nothing is deleted; caches are just not read or written. Everything is rebuilt every boot. Diagnostic/benchmark use only - leave OFF for normal running. |
| `COVERS` | `ON` | COVERS: OFF = no cover art at all (nothing decoded, letter placeholders instead). Diagnostic: isolates list and .nfo cost from cover-decode time. |
| `STRIPROWS` | `10` | STRIPROWS: how many screen rows go to the panel per SPI burst (1-40, default 10). The push is 48 bursts at 10 rows, 12 at 40 - and each burst costs FLUSHUS below. Higher = faster screen updates. Drop it back if you see torn bands. |
| `FLUSHUS` | `500` | FLUSHUS: microseconds to wait after each burst (0-5000, default 500). At the default that is 48 x 500us = 24ms of pure waiting in EVERY frame. 0 is fastest; raise it if the picture tears. |
| `BIGDISK` | `OFF` | BIGDISK: OFF (default) = 1.76 MB set aside for save-game write-back over the cable and for disks sent to a wireless dongle (an Amiga HD disk; the SuperMini's limit). ON = 2.9 MB, for large Atari ST .HFE images (saving to them, or sending them wirelessly). Loading any size over the cable works either way. ON costs ~1.1 MB of memory, so fewer games fit on a big card. Takes effect on the next boot. (Replaces DISKMAXKB.) |
| `LIBLIMIT` | `ON` | LIBLIMIT: ON (default) = if the card holds more games than this GTi can list, stop at boot with a LIBRARY TOO BIG screen and a GTI_CAPACITY.TXT report, so nothing is left out silently. OFF = load as many games as fit and leave the rest out. |
| `DEVMODE` | `ON` | DEVMODE: ON (default) = show the TEST TOOLS button in Settings (SD soak test, reel profiler, no-cache, diagnostic overlay). OFF = hide the button. Their CONFIG.TXT keys still work either way. |
| `LONGNAME` | `OFF` | LONGNAME: OFF (default) = the Gotek sees the loaded disk as DISK.ADF / DISK.DSK (GENERIC images keep a short 8.3 version of their own name, e.g. PROPHECY.HFE). ON = the Gotek sees the image's full file name, e.g. "Prophecy I-The Viking Child-1.hfe" - shown on a FlashFloppy OLED/LCD display. |
| `LIBRARY` | `GEN` | LIBRARY: the library shown at power-on. GEN (default) = /GENERIC (any machine: HFE, ST, IMG, ADF...), ADF = the Amiga .adf library, DSK = the Amstrad CPC .dsk library. Settings > LIBRARY switches it and remembers the choice here. |
| `LISTTILE` | `ON` | LISTTILE: ON (default) = the list's cover panel reuses the reel's cached 45KB thumbnail. OFF = re-decode the full JPEG on every selection change (the old way, and much slower on a big library). Same picture either way. |
| `REELPROF` | `OFF` | REELPROF: ON = print a reel frame-time breakdown to GTI/gti.log every ~1.5s while the reel is on screen. Diagnostic only. |
| `REELBORDER` | `ON` | REELBORDER: frame drawn around each cover in the reel. ON=framed (default), OFF=clean/frameless look (the game you have loaded is still marked green). |
| `LASTUSED` | `OFF` | LASTUSED: ON = on power-up, jump the selection back to the game you last loaded. OFF (default) = always start at the top of the list. |
| `FONT` | `NORMAL` | Font size: SMALL, NORMAL, LARGE |
| `LANG` | `EN` | Language: EN, FR, IT, ES, DE, NL, PL, CS (pull the SD and edit this line if you get stuck) |
| `ROTATE` | `0` | Screen rotation in degrees: 0 or 180 = landscape, 90 or 270 = portrait. |
| `COVERMIN` | `140` | COVERMIN: hide covers whose short side is under N px (0 = show all) - keeps the reel + panel clean. |
| `REELFILTER` | `OFF` | REELFILTER: ON = the reel (cover carousel) shows only games whose cover passes COVERMIN; the A-Z list still shows every game. OFF = reel shows all games. |
| `COMPACT` | `OFF` | COMPACT: OFF = cover art + list, ON = maximise the game list (cover collapses to a strip) |
| `BTNSTYLE` | `PILL` | BTNSTYLE: reel button style. PILL=rounded coloured buttons (default), FLAT=flat bar. |
| `CAP` | `32` | CAP: max wireless dongles the scan will list (default 32, up to 64) |
| `HIVEMIND` | `ON` | HIVEMIND: wireless FLING fan-out. ON=all paired MuCa dongles (classic), OFF=selected dongle only. |
| `GTINAME` | `—` | GTINAME: this screen's name, shown on another screen that shares the same dongle ("in use by DESK"). Up to 24 characters. Empty = GTi-XXXX (from this screen's radio address). |
| `TAPLOAD` | `OFF` | TAPLOAD: ON = tapping the already-highlighted game row loads it (old double-tap) |
| `HOTSWAP` | `OFF` | HOTSWAP: ON = tapping another disk while loaded swaps to it instantly |
| `FORCESWAP` | `OFF` | FORCESWAP: ON = swap disk contents without the USB eject/re-attach cycle |
| `SAVES` | `COPY` | SAVES: save-game persistence. OFF = classic (lost on eject), COPY = kept as GameName.sav.adf beside the master, OVERWRITE = patch the master. |
| `SDSPEED` | `20` | SDSPEED: SD card clock. 20 = default, 40 = ~1.7x faster reads if your card holds it (auto-falls back to 20), 10 = slow and careful. |
| `CATEGORIES` | `OFF` | CATEGORIES: OFF = flat library. ON = browse by category (a top-level folder with no disk images, only subfolders, is a category). |
| `NESTING` | `OFF` | NESTING: OFF = one category level. ON = allow sub-categories (folders within category folders). |
| `SCREENSAVER` | `ON` | SCREENSAVER: idle slideshow. ON = show it after a few minutes idle, OFF = never. |
| `SSMODE` | `SLIDES` | SSMODE: SLIDES = full-screen photo slideshow (default), BOUNCE = bouncing logo, MATRIX = code rain. |
| `SSFX` | `SHUFFLE` | SSFX: transition between slides - SHUFFLE (random), FADE, DISSOLVE, SLIDE, or CUT. |
| `SSTIME` | `6` | SSTIME: seconds each slide is shown (2-120). |
| `SSFAV` | `ON` | SSFAV: ON = also slideshow favourited game covers; OFF = only /screensaver/ images. |
| `LINK` | `ESPNOW` | LINK: dongle transport. ESPNOW = the dongle's own AP + ESP-NOW (default). HOMEWIFI = route the FLING via your home router to a Webby dongle's gotek.local. |
| `HOME_SSID` | `—` | HOME_SSID: your home WiFi name (only used when LINK=HOMEWIFI). |
| `HOME_PASS` | `—` | HOME_PASS: your home WiFi password (only used when LINK=HOMEWIFI). |

## Read by the firmware, not yet an active template key

These keys the firmware **honours** but its self-documenting `CONFIG.TXT` template doesn't write as an active `KEY=` line (so a fresh card doesn't switch them on for you). They work today — add the line yourself. Behaviour below is read straight from the parser. `WEBUI` and `LOG` are now surfaced as **commented hints** in the fresh-card template's "Advanced" block, so upgraders can discover them without the template turning them on. The `WEBUI` / `LOG` / `WIFI_CLIENT_*` rows are the JC3248 / JC4827 web-panel extras; the ESP32-P4 build reads only `SS_IDLE` and `SS_LOAD` from this group. The WebDAV (`DAV_*`) keys are now written into the JC template as of 5.9.8 (see the WebDAV section above); only `DAV_TEST`, a boot smoke-test, stays out.

| Key | Default | What it does |
|-----|---------|--------------|
| `WEBUI` | `OFF` | `ON` = serve the shared web panel over home WiFi (needs `HOME_SSID`/`HOME_PASS` + `LINK=HOMEWIFI`). **Now a commented hint in the template.** |
| `LOG` | `ON` | `OFF` = disable the `/gti.log` diagnostic log (on by default). **Now a commented hint in the template.** |
| `DAV_TEST` | `—` | Smoke test — fetch this one remote path once at boot to prove the wiring. |
| `SS_IDLE` | `—` | Seconds of idle before the screensaver starts (overrides the built-in default). Fine-tuning; intentionally kept out of the template. |
| `SS_LOAD` | `—` | Seconds the load screen lingers before the screensaver may take over. Fine-tuning; intentionally kept out of the template. |
| `WIFI_CLIENT_SSID` | `—` | Alias of `HOME_SSID` (OMEGAWARE-tree name; empty never erases a value set by the other key). |
| `WIFI_CLIENT_PASS` | `—` | Alias of `HOME_PASS` (OMEGAWARE-tree name). |

## Wireless disk size — what the limits are now

- **`BIGDISK`** sets the size of the GTi's RAM disk: the write-back area for saves over the cable, and the buffer a disk is copied into before it is sent to a dongle.
- A wireless disk **bigger** than that RAM disk is no longer refused on the panel: the GTi's own USB serves it straight from the card (as in STANDALONE) and the dongle gets it streamed off the card. The **dongle** sets the limit:
  - **XIAO Webby** (`Webby-1.6.4-xiao-hfe4`): up to about **6 MB** (about 4.7 MB if the board could not reserve its full PSRAM RAM disk at boot).
  - **SuperMini**: 1.76 MB (an Amiga HD disk) — anything bigger shows **TOO BIG** on the panel.
- Saves from a big wireless HFE come back over the save pull as usual (dirty map up to 8 MB).
